## 一、仓库简介

本仓库是本人**全学期课程实验**的统一作品集主仓库，用于：

- 按周归档每一次实验的**源代码、实验报告与结果数据**；
- 记录学习轨迹，便于复盘与查阅；
- 作为课程最终考核的**过程性材料**。

> 本仓库为公开仓库（Public），请勿在其中提交任何**个人隐私、账号密码、密钥**等敏感信息。

## 三、每周提交规范

每次完成实验后，建议按以下格式提交：

```bash
git add week05/
git commit -m "week05: 完成 XXX 实验（简要说明）"
git push
```

**提交信息（Commit Message）建议格式：**

```text
weekNN: 本次实验做了什么
```

例如：
- `week03: 完成数据清洗与可视化`
- `week07: 实现排序算法并对比性能`
