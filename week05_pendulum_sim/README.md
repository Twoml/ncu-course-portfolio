## 四、实验目标

围绕单摆（Pendulum）模型，开展以下工作：

1. 建立单摆运动的**动力学方程**，并推导其解析解；
2. 编写数值求解程序（如 Euler / Runge-Kutta 法），模拟摆角随时间的变化；
3. 对比**小角近似**与**真实非线性解**的差异；
4. 输出摆角-时间曲线与相图，分析周期随初始摆角的变化规律。

> 单摆模型是振动系统的经典原型，其周期公式
> `T ≈ 2π√(L/g)`（小角近似）与真实周期在大摆角下会明显偏离，
> 这一"理想模型 vs 真实系统"的偏差，与食品质构分析中的
> 弹性/黏弹性响应建模在数学方法上是相通的。
